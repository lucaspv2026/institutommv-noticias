# Notícias do Instituto MMV

Arquivo de dados das notícias publicadas em https://institutommv.com.br/noticias.
O site lê `noticias.json` deste repositório. Atualizado diariamente.

Formato de cada item: `id`, `data` (AAAA-MM-DD, data do fato ou da publicação original), `area`, `titulo`, `resumo` (texto próprio, 2 a 4 frases), `fonte`, `url` (fonte original).
